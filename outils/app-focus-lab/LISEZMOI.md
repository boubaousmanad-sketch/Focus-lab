# App FOCUS LAB : mises à jour

L’app FOCUS LAB (FOCUS ON) est hébergée sur ChatGPT Sites. ChatGPT Sites ne se met pas à jour depuis GitHub : ce dossier garde donc la dernière version des instructions à lui donner.

| Fichier | Rôle |
| --- | --- |
| `mise-a-jour.txt` | Les changements à appliquer à l’app : menu Nutrition, plan nutrition des clients, bouton Déconnexion, programmes, style |
| `guide-style.txt` | Couleurs, police, boutons, cartes et mouvement du site, à reprendre dans l’app |

Les deux fichiers sont en ligne :

- https://focusandperformance.com/outils/app-focus-lab/mise-a-jour.txt
- https://focusandperformance.com/outils/app-focus-lab/guide-style.txt

## Mettre l’app à jour

Dans ChatGPT, ouvre la conversation de l’app FOCUS ON et envoie :

> Lis https://focusandperformance.com/outils/app-focus-lab/mise-a-jour.txt et applique toutes ces instructions à mon app, sans rien supprimer.

Si ChatGPT ne peut pas ouvrir le lien, ouvre-le toi-même, copie tout le texte et colle-le dans ChatGPT.

Quand les instructions changent, ce fichier est mis à jour ici : il suffit de renvoyer la même phrase.

Le mot de passe du coach et le lien d’accès direct à l’outil nutrition ne vont jamais dans ces fichiers ni dans le code de l’app.
